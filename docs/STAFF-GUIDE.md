# Panduan Staf Booth · Cikgu Sehari & Misi Pelajar Bijak · PESKON UPSI 2026

*(Sumber untuk `assets/print/staff-guide-peskon26.pdf`.)*

## 1. Sebelum booth dibuka

1. **Projektor:** buka Chrome di laptop → `bsa-cikgu-sehari.netlify.app/tv?e=peskon26` → klik sekali untuk skrin penuh.
   Skrin ada dua papan: **Top Cikgu Sehari** dan **Top Pelajar Bijak** (5 teratas setiap satu).
   Sambung internet (hotspot telefon pun boleh) dan cas laptop.
2. **Poster QR:** tampal di meja dan di banner (cetak A4 atau A3).
3. **Telefon staf:** log masuk `bsa-cikgu-sehari.netlify.app/admin`.
4. **Uji sekali:** imbas QR dengan telefon sendiri dan pastikan permainan terbuka.

## 2. Semasa booth

- **Ajak:** *"Jom main, 3 minit je! Imbas QR ni."* Satu QR, dua permainan.
- **Pelajar / graduan UPSI** → pilih *Pelajar / graduan UPSI* → main **Cikgu Sehari** (semak kerja murid, dapat jenis
  cikgu) → **peluang jadi tutor BSA** (RM25–40/jam).
- **Adik-adik sekolah** → pilih *Pelajar sekolah* → main **Misi Pelajar Bijak** (Kuiz Kilat dengan satu bantuan
  *"Tanya Cikgu BSA"*, dapat jenis pelajar dan cara belajar terbaik) → **trial percuma 3 subjek**, kod **PESKON UPSI 2026**.
- **Ibu bapa / keluarga** → pilih sendiri permainan mana → trial percuma 3 subjek untuk anak.
- **Hadiah** (ikut stok, tidak direkod dalam sistem; semak skrin pemain):
  - **Semua pemain:** sticker ringkas.
  - **Adik-adik / keluarga yang daftar trial** (skrin *"Tahniah! Trial anda sedia"*): **beg anyaman BSA** (sticker cikgu +
    flyer) dan **buku nota kecil** selagi ada (lebih kurang 10 sahaja).
  - **Pelajar / graduan UPSI yang daftar tutor:** sticker sahaja (tiada beg).
  - **Ibu bapa yang terus daftarkan anak di booth:** beg. Stok beg (lebih kurang 120) dikongsi untuk semua ini.
  - Satu beg untuk satu keluarga. Kalau skrin tunjuk *"Nombor ini sudah didaftarkan"*, beg sudah diambil.
- Papan skor bermula semula setiap hari pada tengah malam.

## 3. Susulan (laman admin)

- **Pendaftaran:** tekan **WhatsApp** → mesej sudah ditulis → hantar.
- **Status:** pelajar *Dihubungi → Trial ditempah → Mendaftar*; tutor *Dihubungi → Ditemu duga → Diambil*. Tulis nota.
- Admin boleh **muat turun CSV**.
- Sasaran: hubungi semua dalam **24–48 jam**.

## 4. Kalau ada masalah

| Masalah | Apa nak buat |
|---|---|
| Nama tak sopan di projektor | Admin → **Papan skor** → tekan ikon mata untuk sembunyi |
| Ikon wifi kuning di projektor | Internet lemah. Ia sambung semula sendiri |
| Pemain dapat mesej "talian lemah" semasa daftar | Tekan **Cuba lagi**, atau **Teruskan ke WhatsApp** (maklumat sampai melalui WhatsApp) |
| "Nombor ini sudah didaftarkan" | Satu nombor, satu tuntutan. Rujukan yang sama digunakan |
| Tak boleh log masuk admin | Hubungi admin BSA |

## 5. Maklumat penting

- Kod **PESKON UPSI 2026**: trial percuma 3 subjek, sah hingga **2 Disember 2026**
- WhatsApp BSA: **011-7523 4588**
- Tutor: RM25–40/jam, bayaran mingguan. Pelajar UPSI: semester 5 ke atas, CGPA 3.3 ke atas.
